## DEC-001 — Multi-page premium site; WhatsApp is the single conversion
**Data:** 2026-10-09 · **Etapa:** triagem + metas
**Decisão:** Build a complete multi-page site with premium/authority positioning. The only conversion is WhatsApp (`wa.me`), with a message pre-filled with the project name and code. It appears in the header nav and in the Tear Ticket at the close of the home, project and contact pages. There is no floating bubble.
**Why:** The developer chose "chamar no zap". Success means clients arrive citing a specific project, so the message must carry that project. A floating green bubble breaks the gallery aesthetic, and the scout shows it reads as a service provider.
**Affects:** `PAGE_BLUEPRINTS.md`, `src/lib/whatsapp.ts`, Tear Ticket, header.
**Alternativas descartadas:** a detailed "Iniciar um projeto" form (CARGO-style); a floating WhatsApp widget.
**Reversível:** sim

## DEC-023 — Implementation drift reconciled (execution phases 01–08)
**Data:** 2026-10-10 · **Etapa:** drift check pós-implementação

**Decisão — what the code does differently from the earlier docs (docs updated to match):**
1. **Shared image card → project uses the View Transitions API** (`navigate(to, { viewTransition: true })` + `view-transition-name: project-image` set on the clicked image and on the project opening). It replaces motion `layoutId`: there is no extra library, and it works across lazy routes. Browsers without VT get the ink wipe instead.
2. **React Router 8** (the docs said 7). `createBrowserRouter` with lazy routes and `HydrateFallback`.
3. **Header gets a white background when not over the hero.** On a white page this is visually "no bar", but it stops text from colliding under the fixed header while scrolling.
4. **The project opening starts below the header** (`mt-[76px]`, 92svh − 76px). The header stays ink and the photo is framed like a gallery wall. Reason: white nav over bright skies failed contrast.
5. **Fonts are self-hosted from `public/fonts/`**, with Michroma copied from @fontsource and Aktiv subset to woff2. Both are preloaded in `index.html`; the @fontsource dependency was removed. Aktiv files are gitignored.
6. **Hero NORD row** is positioned from the computed roof line (`top = roofPx − 0.72 × rowHeight`), so the letters always dip behind the house on any aspect ratio. Framing alone could not guarantee it on near-square screens.
7. **Gallery layout picks spans by aspect** (landscape → wide, portrait/near-square → narrow, alternating), keeping the "never the same size twice in a row" rule.
8. **Vendored React Bits patches** (`scripts/patch-reactbits.py` + manual): type-only imports, light surfaces, no shadows/radius, decorative Drift Wall tiles (aria-hidden, paused offscreen), Accordion `onOpen`, TiltedCard reduced-motion guard, and TearTicket **tap-to-tear** plus a pt-BR status text.
9. **Team portraits = monogram placeholder** (MED-T1 option B, CNT-007). No AI generation was done, so U11 is not triggered.

**Why:** These were found during implementation and browser verification (Playwright, 1440 / 1235 / 390 px) and are all improvements or necessary fixes.
**Affects:** `MOTION_DIRECTION.md`, `SITE_ARCHITECTURE.md`, `PAGE_BLUEPRINTS.md`, `DESIGN.md`, `DESIGN_SYSTEM.md`, `CONTENT_PENDING.md`, `MEDIA_PLAN.md`.
**Reversível:** sim
