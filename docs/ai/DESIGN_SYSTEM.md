## Visual Direction

*"A parede branca antes da foto"*: the white wall comes before the photograph. The mechanism is **space**.

The site is a silent white gallery, and the only thing allowed to carry colour is the architecture photography.

- **Form:** a rigid asymmetric 12-column grid with sharp edges (radius 0). The single non-orthogonal form is the monogram's **33.7° roof diagonal**.
- **Type:** Michroma for the wordmark and project names, Newsreader for the manifesto and concept, Aktiv for reading (DEC-032).

## Color Foundations

Light mode only. There is no accent colour (DEC-007).

| Token | Hex | Role | Pair contrast |
|---|---|---|---|
| `--color-bg` | #FFFFFF | page, surfaces | — |
| `--color-text` | #0B0B0C | text, interactive borders, inverted fill, focus | 19.7:1 on bg |
| `--color-muted` | #6B6E72 | secondary text, captions' place/year, disabled | 5.1:1 on bg (AA) |
| `--color-border` | #E4E6E8 | hairline dividers only (non-interactive) | 1.25:1, decorative |
| `--color-primary` / `--color-primary-fg` | #0B0B0C / #FFFFFF | inverted states (Tear Ticket hover, selection) | 19.7:1 |

**State rules**
- **Hover, text link:** underline, 1 px, offset 6 px.
- **Hover, Tear Ticket:** full inversion (ink fill, white text).
- **Active nav item and active filter tab:** underline.
- **Focus:** `outline: 2px solid #0B0B0C; outline-offset: 2px`. Over photos, a double ring (`box-shadow: 0 0 0 2px #fff, 0 0 0 4px #0B0B0C`). This is the only allowed box-shadow, because it is a focus ring and not elevation.
- **Selection:** `::selection { background: #0B0B0C; color: #fff }`.

**Text over photo**
- Allowed only in the hero, on the Accordion code labels and in the wipe overlay (which is ink, not a photo).
- Measure the mean relative luminance of each hero photo's text zone at build time (`scripts/images.mjs` writes `luma` per hero into the manifest).
- Thresholds: ≤ 0.18 for 11 px labels (≥ 4.5:1) and ≤ 0.30 for giant letters (≥ 3:1).
- If a photo fails, re-frame it via `roofLine` or choose another photo. No scrim, gradient or text-shadow.

## Spacing Scale

- **Base unit:** 8.

| Token | 1 | 2 | 3 | 4 | 6 | 8 | 12 | 16 | 20 | 35 |
|---|---|---|---|---|---|---|---|---|---|---|
| px | 8 | 16 | 24 | 32 | 48 | 64 | 96 | 128 | 160 | 280 |

Also `--space-0_5: 4px`.

- **Section rhythm:**
  - `--sec-s: clamp(64px, 8vw, 96px)`
  - `--sec-m: clamp(96px, 12vw, 160px)`
  - `--sec-l: clamp(160px, 18vw, 280px)`
- **Rule:** never use the same section gap three times in a row. A dense section is followed by a long pause (anti-U13).

## Containers and Grid

| Band | Range | Columns | Margin | Gutter |
|---|---|---|---|---|
| Mobile | < 640 | 1 (4 virtual for offsets) | 20px | 24px |
| Tablet | 640–1023 | 8 | 32–51px | 24px |
| Desktop | 1024–1439 | 12 | 51–72px | 24px |
| Wide | ≥ 1440 | 12 | 72–96px | 24px, max 1600px |

- **Margin token:** `--margin: clamp(20px, 5vw, 96px)`.
- **Images:**
  - Opening and hero images are full-bleed; gallery images may bleed one side.
  - Ratios are only 3:2 and 4:5. Size encodes importance.
  - Masonry (Grade view) uses CSS columns 3 / 2 / 1 with `break-inside: avoid`. Real heights come from the manifest, so there is no CLS.

## Radius and Shadows

- **Radius:** 0 on every element: images, tickets, panels, focus rings.
- **Shadows:** none. Separation is space, then a 1 px hairline. The focus double ring is the only box-shadow.
- **Borders:** 1 px. `--color-border` for dividers, `--color-text` for interactive outlines (Tear Ticket, inputs if any).

## Essential Components

| Component | Rules |
|---|---|
| **Header** | Fixed. Lockup on the left; Projetos, Estúdio and WhatsApp (text link) on the right. Transparent over the hero, white elsewhere, ink type. White type only when a loaded hero photo has luminance ≤ 0.18. Mobile: "Menu" opens a white panel (DEC-032). |
| **Footer** | Hairline on top. Wordmark · nav · e-mail · Instagram · city SC · study notice · Créditos · Privacidade. `.t-caption` muted. |
| **Text link** | Ink, no underline at rest; underline on hover and focus. External links get `↗`. Arrows are allowed only on "Ver os projetos →" closing links, never on cards. |
| **Buttons** | There are no conventional buttons. Interactive controls are text tabs (filter, view toggle), the "Menu" toggle and the Tear Ticket. Tabs are `.t-label`; the active tab is underlined; `aria-pressed` / `aria-selected`. |
| **Project card** | Photo plus caption `**Name** · Place · Year`. The whole card is one `<a>`. No hover zoom on the card (motion is reserved); the caption name gets an underline on hover. |
| **Index row** | Grid `5em 1fr 12em 5em`: code · name (`.t-h3`) · city · year, with a hairline bottom. Hover: the name is underlined and a desktop preview follows the cursor. |
| **Ficha técnica** | `<table>`: `.t-label` key and Aktiv value, hairline under each row. |
| **Section header** | `.t-label` on the left, an optional count on the right, a hairline above. No eyebrow + h2 + paragraph stack (anti-U13). |
| **Tear Ticket** | See PAGE_BLUEPRINTS → Component spec. White, 1 px ink border, dashed perforation, radius 0, `tearAngle` 33.7. |
| **Tags/badges** | None. Category is plain text in the caption or the ficha. |
| **Form fields** | None in this project (WhatsApp only). |

## Responsive Principles

- **Mobile is designed, not collapsed.**
  - The single column keeps a variable rhythm: alternate 100% width, 80% offset to the right, and 4:5 centred.
  - Hover-only features get explicit replacements: the cursor preview becomes thumbnails, the Tilted Card is static, and the Tear Ticket tears on tap.
- **Touch targets** are ≥ 44×44 px: nav items, filter tabs and the ticket stub.
- **Hero on mobile:** letters at their minimum size, labels hidden, parallax off. Framing still respects `roofLine`.

## Asset Guidelines

- **Photos:**
  - Only via the image pipeline (AVIF/WebP, 5 widths).
  - `<picture>` with explicit width and height.
  - `loading="lazy"` everywhere except the hero and project openings.
- **Hero:** photo + cutout PNG→AVIF with alpha. The two layers share `object-fit` and `object-position` exactly.
- **Logo:** inline SVG component `<Monogram />`, stroke-based so the preloader can draw it. Favicon from a simplified mark (16 px legibility test pending, CNT-001).
- **Alt text:** describe the architecture (material, form, light, place) in pt-BR.
