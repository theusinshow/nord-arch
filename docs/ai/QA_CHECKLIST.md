## Responsive
- [ ] Reviewed at 360, 390, 768, 1024, 1440 and 1920.
- [ ] No overflow, cut content or overlap. The hero letters never collide with the header.
- [ ] Hero framing: the top row dips behind the roof at every width (`roofLine`).

- [ ] The mobile replacements work: thumbnails instead of the cursor preview, a static Tilted Card, and tap-to-tear.

## Accessibility — target: AA
- [ ] One H1 per page, a coherent heading order, landmarks, and a skip link.
- [ ] Full keyboard navigation in a logical order. The Tear Ticket tears on Enter/Space. Accordion panels expand on focus.
- [ ] Visible focus on every interactive element: 2 px ink, or a double ring over photos.
- [ ] Contrast:
  - `#0B0B0C`/`#FFFFFF` 19.7:1
  - `#6B6E72`/`#FFFFFF` 5.1:1
  - white text on hero photo: luma ≤ 0.30 for letters, ≤ 0.18 for labels (from the manifest)
- [ ] Meaningful pt-BR alt text on every photo. Decorative duplicates (Drift Wall clones) use `alt=""` and `aria-hidden`.
- [ ] `prefers-reduced-motion` behaves exactly as `MOTION_DIRECTION.md` → Accessibility, item by item.
- [ ] Forms: N/A (no forms).

## SEO — scope: baixo (private study, noindex)
- [ ] A unique title and meta description per page, from `PAGE_BLUEPRINTS.md`.
- [ ] One H1 per page.
- [ ] `<meta name="robots" content="noindex,nofollow">` on every route.
- [ ] Internal links coherent; no orphan pages.
- [ ] Open Graph: waived. Local schema / NAP: waived. See the Waivers table in `DECISIONS_LOG.md`.

## Performance — target: budget
- [ ] LCP < 2.5 s, CLS < 0.05, INP < 200 ms (Lighthouse mobile on `npm run preview`).
- [ ] Initial JS ≤ 250 KB gzip. Each lazy route ≤ 60 KB. gsap is absent from the initial chunk (DEC-019).
- [ ] Hero photo ≤ 300 KB + cutout ≤ 150 KB (AVIF @1920). The hero photo is preloaded with `fetchpriority="high"`.
- [ ] Gallery images ≤ 220 KB AVIF @1440, lazy below the fold, width/height set from the manifest.
- [ ] Fonts: ≤ 4 woff2, ≤ 90 KB total, `font-display: swap`, Michroma preloaded, metric fallbacks.
- [ ] The Drift Wall and cursor-preview rAF pause offscreen. 60 fps on the Home scroll (Performance panel).
- [ ] No console errors or warnings.

## Design fidelity
- [ ] Matches the `DESIGN.md` tokens: colours, type table, spacing, radius 0, no shadows.
- [ ] Design rules honoured: no accent colour, no scrim or gradient over photos, uppercase only in the wordmark and hero, no weight 700.
- [ ] The hero matches the approved prototype (`_explore/motion/index.html`) plus the refinements agreed in phase 05.
