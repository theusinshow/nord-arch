## How to use skills in each phase

The session mode is **A (Completo)**: recommended skills may be used in any phase when they improve the result.

The catalog marks these skills `target`. On 2026-10-10 they were **detected as available** in this Claude Code environment's skill list:

- `impeccable`
- `frontend-design`
- `webapp-testing`
- `web-design-guidelines`
- `react-best-practices`
- `composition-patterns`
- `copywriting` (project-local, `.agents/skills/copywriting`)
- `higgsfield-generate`

Before invoking any of them:
1. Confirm it still appears in the available-skills list.
2. Propose it, state the expected output, and **ask the developer's approval**.
3. If it is unavailable, fall back to `references/*` and say which skill would have helped.

Never run two overlapping visual skills on the same decision (`impeccable` vs `frontend-design` vs `ui-ux-pro-max`).

Every phase ends with:
- a report of changed files, decisions and pending issues;
- new decisions appended to `DECISIONS_LOG.md`;
- verification in the browser (`npm run dev` + Playwright screenshot) before claiming the phase is done.

## Phase 01 — Project foundation
### Goal
Scaffold, tokens, fonts, router and the global shell.

### Tasks
- `npm create vite@latest . -- --template react-ts`. Keep `docs/`, `_explore/` and `_input/`.
- Install the dependencies:
  - `react-router` (7)
  - `tailwindcss` + `@tailwindcss/vite` (v4)
  - `motion`
  - `gsap`
  - `@fontsource/michroma`
  - dev: `sharp`
- Configure TS strict and the path alias `@/` → `src/`. Add a minimal `components.json` for the shadcn registry.
- `src/styles/index.css`: paste the tokens from `DESIGN_SYSTEM.md` (`@theme`), add `@font-face` for Aktiv, `::selection` and `:focus-visible`.
- Aktiv Grotesk: convert `C:\Dev\webdesign\Fonts\Aktiv Grotesk\OTF\AktivGrotesk-{Regular,Medium}.otf` to woff2 latin subset with `pyftsubset` and put them in `src/assets/fonts/`. **Add them to `.gitignore`** (licensed).
- Router (`createBrowserRouter`): `/` eager; `/projetos`, `/projetos/:slug`, `/estudio`, `/contato`, `/creditos`, `/privacidade` and `*` with `lazy()`.
- `index.html`:
  - `<meta name="robots" content="noindex,nofollow">`
  - `lang="pt-BR"`
  - preload the Michroma woff2
- Layout shell:
  - `<Header>` with lockup + nav and the white/ink tone prop
  - `<Footer>` with the study notice
  - skip link
  - scroll restoration
- `<Monogram />` from the prototype trace (CNT-001 placeholder).

### Recommended skill
`react-best-practices` (setup review).

### Done when

- `npm run build` passes `tsc` strictly.

## Phase 01b — Media pipeline and curation
### Goal
Turn the Divisare folders into optimised, credited, curated assets.

### Tasks
- `scripts/contact-sheet.py`: one contact sheet per roster folder in the scratch/`_explore`, so picks can be made by eye.
- `scripts/images.config.json`: per slug, list `opening`, `card`, `gallery[]` (6–12, ordered) and optional `drawings[]`, following the curation rules in `MEDIA_PLAN.md`. Add 12–18 Drift Wall tiles from the roster and reserve.
- `scripts/images.mjs` (sharp):
  - copy the originals into `assets-src/` (gitignored);
  - encode AVIF q50 and WebP q72 at 640/960/1440/1920/2560 (capped at source width) into `public/img/<slug>/`;
  - write `src/content/images.manifest.json` with w, h, ratio and `luma` for heroes.
- `scripts/cutout.py`:
  - re-do the hero sky extension at full resolution;
  - run rembg `isnet-general-use`;
  - write the alpha PNG, then let `images.mjs` encode AVIF/WebP with alpha;
  - record `roofLine`.
- Verify the hero weight is ≤ 450 KB at 1920w.

### Recommended skill
None (scripted). Ask the developer to approve the picks via the contact sheets.

### Done when
The manifest covers 12 projects + the Drift Wall set, the hero passes the luminance and weight checks, and the cutout edge has been reviewed.
