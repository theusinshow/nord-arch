### Responsive behavior
- **Hero:**
  - Mobile: letters at `clamp` minimum 56 px, labels hidden, parallax off, entrance scale 1.06.
  - Framing still uses `roofLine` for the top row to dip behind the roof.
- **Drift Wall:** 3 columns on mobile with no tilt. With reduced motion, a static grid.
- **Accordion:** on mobile, a vertical stack of 3:2 images with captions always visible.
- **Tear Ticket:** full width on mobile. Tap tears it.
