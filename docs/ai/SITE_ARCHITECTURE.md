## Global Navigation Rules

- **Header:**
  - Fixed. Transparent with white text over the hero; a white background (same as the page) everywhere else, so content never collides under it (DEC-023).
  - Lockup on the left (monogram + "NORD ARCH" wordmark, linking to `/`).
  - Nav on the right: **Projetos · Estúdio · WhatsApp**.
  - The "WhatsApp" item opens `wa.me` with the generic message. It is a text link, never a green bubble.
  - Colour is white while over the hero photo and ink elsewhere, with a 600 ms colour transition.
- **Mobile header:** lockup + "WhatsApp" + a "Menu" text toggle that opens a full-screen white panel with **Projetos · Estúdio · Contato · WhatsApp** in Michroma `h2` size. No hamburger icon.
- **Desktop nav** has no "Contato" item on purpose: "WhatsApp" is the contact action. `/contato` is reached from the footer and the mobile menu.
- **Footer (all pages):**
  - wordmark
  - nav repeated: Projetos · Estúdio · **Contato** · WhatsApp
  - e-mail and Instagram (placeholders)
  - fictional headquarters city in SC
  - the study notice (CNT-018)
  - a link to `/creditos`
  - a link to `/privacidade`

  No newsletter and no social icons grid.
- **Transitions (DEC-016):**
  - card, Accordion, index row or "próximo projeto" → project: shared image
  - everything else: the 33.7° ink wipe
- **Scroll:** native, with no scroll-jacking. Every route change restores to top, except history back, which restores the previous position.
- **Robots:** `<meta name="robots" content="noindex,nofollow">` on every route.

## Page Architecture

### Home `/`
- **Objective:** recognise the authorial language and pick a house.
- **Sections:**
  1. Hero NORD/ARCH (photo of NA—01)
  2. Manifesto (1–2 sentences)
  3. Drift Wall band (88vh)
  4. Highlights (Accordion Gallery, 5 works)
  5. Index link ("12 obras · NA—01 → NA—12")
  6. Tear Ticket `home`
  7. Footer
- **Primary CTA:** Tear Ticket `home` (WhatsApp, generic plot message).
- **Notes:** the hero photo is the LCP element. The Accordion and gsap load on approach (DEC-019).

### Índice `/projetos`
- **Objective:** find the project that matches their plot.
- **Sections:**
  1. Title + count
  2. Filter tabs (Todas · Residencial · Interiores · Paisagismo · Comercial) + view toggle (Lista · Grade)
  3. List view: rows of code · name · city · year, with a cursor preview on desktop and thumbnails on mobile
  4. Grade view: masonry wall, 3:2 / 4:5, museum captions
- **Primary CTA:** open a project. **No Tear Ticket** (anti-U14).
- **Notes:** the filter and view are kept in the query string (`?categoria=residencial&vista=grade`) so a shared link reproduces the view.

### Projeto `/projetos/:slug`
- **Objective:** turn affinity into a conversation about this house.
- **Sections:**
  1. Opening image (shared-image target)
  2. Name + place · year + code
  3. Ficha técnica
  4. Concept (1 paragraph)
  5. Editorial gallery (variable rhythm)
  6. Drawings (optional, if any exist in the source folder)
  7. Tear Ticket `project`
  8. Next project (card with shared image)
- **Primary CTA:** Tear Ticket `project`, the main CTA of the site.
- **Notes:** an unknown slug renders the 404. "Next" wraps from NA—12 to NA—01.

### Estúdio `/estudio`
- **Objective:** authorship and scope.
- **Sections:**
  1. Manifesto (3–5 short sentences, Michroma)
  2. Language: Materiais · Luz · Lugar, each tied to a cited project with an image and a link
  3. Scope: projeto → obra (one interlocutor)
  4. Team (Tilted Card, fictional)
  5. Closing link to `/projetos`
- **Primary CTA:** link to `/projetos`. **No Tear Ticket.**

### Contato `/contato`
- **Objective:** convert.
- **Sections:**
  1. Title
  2. Tear Ticket `contact` (large, vertical, protagonist)
  3. Alternatives: e-mail · Instagram · city (SC)
- **Primary CTA:** Tear Ticket `contact`. Its message is a script asking for plot city, programme and reference project.

### Créditos `/creditos`
- **Objective:** attribution.
- **Sections:**
  1. Study notice
  2. Table: code · fictional name → original project · architect · photographer · source (Divisare)
  3. Fonts and licences, and the React Bits components used
- **Primary CTA:** none.

### Privacidade `/privacidade`
- **Objective:** a short LGPD text stating no cookies, no tracking and no forms. The WhatsApp link opens a third-party app.
- **Primary CTA:** none.

### 404
- **Objective:** recover.
- **Sections:** monogram, "Esta página não existe.", a link to `/projetos`.
- **Primary CTA:** link to the index.

## SEO / Accessibility / Performance Requirements

- **SEO (low priority, DEC-014 waiver):**
  - unique `<title>` and meta description per route (see PAGE_BLUEPRINTS)
  - `noindex,nofollow`
  - no sitemap and no structured data
- **Accessibility, WCAG AA:**
  - landmarks (`header`, `nav`, `main`, `footer`), with one `h1` per page
  - skip link
  - full keyboard path: the Tear Ticket is a `button` that tears on Enter/Space; the Accordion panels are links that expand on focus
  - visible focus: 2 px ink, or a double ring over photos
  - alt text on every photo
  - `prefers-reduced-motion` honoured by every effect
- **Performance:**
  - LCP < 2.5 s · CLS < 0.05 · INP < 200 ms
  - initial JS ≤ 250 KB gzip, each lazy route ≤ 60 KB
  - images: AVIF + WebP via `<picture>` with width/height from the manifest
  - hero photo preloaded with `fetchpriority="high"`

## Asset Guidelines
- Optimised images only, generated by `scripts/images.mjs`: AVIF q50 / WebP q72 at 640 / 960 / 1440 / 1920 / 2560, capped at each source's native width (never upscale).
- SVG for the logo and the monogram. Inline SVG icons only if needed; there is no icon set.
- No text embedded in images. All the hero letters are live text.
- Meaningful pt-BR alt text that describes the architecture, for example: "Volume de madeira escura com empena, sobre afloramento de rocha, ao entardecer". Never "imagem 1".
- No video and no 3D in this phase.
