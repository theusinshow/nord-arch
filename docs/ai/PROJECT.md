## Primary User Journey

### User
A high-income couple building their own house. They are experts: they arrive with a plot, a programme and references, and they decide together, sharing links over weeks.

### Need
To find out whether Nord Arch's language matches theirs, and to find "their" house in the portfolio.

### Entry source
A shared link: WhatsApp or Instagram between the couple, or a referral. Mobile matters as much as desktop.

### Expected path
1. They land on `/`. The hero shows the language in under 10 s, followed by the manifesto.
2. Drift Wall: the language is shown as consistent across many works.
3. The Accordion highlights let them pick a house, or the index offers all 12.
4. On `/projetos/:slug` they read the opening, the ficha técnica, the concept and the gallery.
5. The `project` Tear Ticket sends a WhatsApp message citing that house.
6. Alternative route: from `/estudio`, to understand scope and authorship, then `/projetos`, then a project.

### Main objections
- **Aesthetic affinity** (primary): "a linguagem deles combina com a nossa?"
- Scope: does the studio follow the work through to the end? This is answered in `/estudio` and in each project's scope row.

### Conversion action
The Tear Ticket: drag the stub past the threshold, or tap/click it, or press Enter/Space. Its message carries `{name} ({code})`.

### Abandonment risks
- **Heavy hero, slow LCP.** Mitigation: a 450 KB hero budget and preload (DEC-014).
- **Motion that feels like a demo** or hides content. Mitigation: retheming and intensity by rarity (DEC-009).
- **Mobile users who never discover the drag gesture.** Mitigation: tap-to-tear plus a visible "Destaque aqui" affordance.
- **Projects that read as photos without argument.** Mitigation: a concept paragraph and a ficha in every project.

## Content model

This is the authoritative schema for `src/content/projects.ts`; `images.manifest.json` resolves sizes.

```ts
export type Ratio = '3:2' | '4:5' | '16:9';
export type ImgRole = 'opening' | 'card' | 'gallery' | 'drawing' | 'drift';

export interface Img {
  src: string;          // base path without width/extension, e.g. '/img/pleat-house/03'
  w: number; h: number; // native size, from the manifest
  ratio: Ratio;
  alt: string;          // pt-BR, describes the architecture (CNT-009)
  role: ImgRole;
}

export type Category = 'Residencial' | 'Interiores' | 'Paisagismo' | 'Comercial';
export type Scope = 'arquitetura' | 'interiores' | 'paisagismo' | 'obra';

export interface Project {
  slug: string;               // 'pleat-house'
  code: `NA—${string}`;       // 'NA—03' (em dash)
  order: number;              // 1..12, drives "próximo projeto" (wraps)
  name: string;               // 'Pleat House'
  place: string;              // locality, e.g. 'Rancho Queimado'
  city: string;               // municipality
  state: 'SC';
  year: number;               // 2019..2025
  category: Category;
  area: number;               // m², fictional (CNT-004)
  program: string;            // fictional (CNT-004)
  scope: Scope[];
  team: string[];             // fictional names (CNT-007)
  concept: string;            // 1 paragraph (CNT-005)
  featured: boolean;          // Home Accordion: NA—01, 02, 05, 06, 08
  images: Img[];              // ordered; exactly one 'opening' and one 'card'
  hero?: { src: string; fg: string; roofLine: number; luma: number }; // NA—01 only
  fictional: true;
  credit: { architect: string; photographer: string; source: 'Divisare'; sourceTitle: string };
}
```
