# Motion Direction

> Generated by Coded by M — Site Architecture System. Source of truth: `/docs/ai/DISCOVERY.md` and `/docs/ai/DECISIONS_LOG.md`.
> **Living reference:** `_explore/motion/index.html`, the approved vanilla prototype. Serve it with `python -m http.server 8765` from that folder. Specs here override the prototype where they differ (DEC-016, DEC-018).

## Core Motion Concept

*The site seems still until a gesture happens: the house reveals itself, the wall breathes, the invitation tears.*

- **Intensity:** expressive **by rarity** (DEC-009). Few strong moments, and silence everywhere else.
- **Character:** slow and heavy, like light moving across a volume. Nothing bounces, except the Tear Ticket stub springing back.
- **Signature form:** the monogram's **33.7° roof diagonal** is used in reveals, the page wipe and the tear.

## Motion Language

| Token | Value | Use |
|---|---|---|
| micro | 200ms | hover, focus, press, colour/underline |
| ui | 600ms | captions, preview clip, header tone, wipe half |
| reveal | 1200ms | image reveals, Accordion expand, shared image |
| hero | 1200ms | hero letters (each) |
| hero-photo | 2400ms | hero photo settle |
| ease-out | `cubic-bezier(.2,.7,.1,1)` | entrances, reveals |
| ease-inout | `cubic-bezier(.7,0,.2,1)` | page wipe, shared image |
| spring-back | `cubic-bezier(.2,1.4,.3,1)`, 900ms | Tear Ticket stub returning (the only overshoot) |
| distance | letters 105% of mask height · list 0 (no layout motion) | — |
| angle | 33.7° | reveal edge, wipe edge, max stub rotation |

**Rule:** animate `transform`, `opacity` and `clip-path` only. Never animate layout properties in response to scroll.

Declared exceptions (DEC-022):
1. The **Accordion Gallery** animates panel width on hover/focus. This is the component's own behaviour, triggered by the user and never by scroll.
2. The **Tear Ticket stub return** uses the only overshoot curve (`spring-back`), because it is paper being released.
3. **Rotations** that are motion, not form: the falling stub at 48°, the Drift Wall tilt of ±3° and the Tilted Card at ±5°. The "33.7° is the only non-orthogonal form" rule covers static shapes, masks and edges.

## Hierarchy
1. **Primary narrative motion:** the hero entrance and layered parallax; the preloader monogram draw (first visit only).
2. **Section transitions:** the shared image card→project; the 33.7° ink wipe for all other navigation; diagonal image reveals.
3. **Microinteractions:** the Tear Ticket; the Accordion expand; the index cursor preview; the Tilted Card; link underline, header tone and focus.
4. **Decorative motion:** the Drift Wall band. It is the only continuous motion, it runs only while visible, and it stops under reduced motion.

### Entrance timeline (absolute, first visit; t in ms)

| t0 → t1 | Layer |
|---|---|
| 0 → 750 | preloader strokes (3 paths, staggered 150) |
| 750 → 1200 | preloader diagonal exit (overlaps the hero) |
| 750 → 3150 | hero photo + cutout `scale 1.12 → 1` (ambient, non-blocking) |
| 750 → 2510 | hero letters N…H (8 × 80 ms stagger, 1200 ms each): **hero legible ≈ 2.5 s** |
| 1700 → 2300 | hero labels opacity |

On repeat visits (no preloader), t0 is the `decode()` resolution and everything shifts left by 750 ms: letters are done at ≈ 1.76 s. LCP is the photo paint (preloaded) and never waits for the letters.

## Drift Wall tiles

The tiles are **decorative**: they are not links and carry `aria-hidden`, with `alt=""` on the duplicate clones. Navigation from the band happens only through the plate link "Ver os 12 projetos" (wipe transition). There are 12–18 tiles from the roster and the reserve (MEDIA_PLAN MED-D1).

## Microinteractions

- Hover never moves layout. No padding or width animation on list rows.
- Cards do not zoom on hover. The only hover feedback is the caption underline. Image motion is reserved for reveals and the shared-image transition.
- Focus mirrors hover, so every hover affordance also exists on `:focus-visible`.

Target 60 fps on a mid-range phone. If the Drift Wall drops frames, reduce it to 2 columns.

## Accessibility

Respect `prefers-reduced-motion: reduce` (system) everywhere:

- **Become instant:** the preloader is skipped; the hero goes straight to its final state; the wipe becomes a direct route swap; the shared image is a direct swap; reveals have `clip-path: none`; the Accordion swaps panels with no transition.
- **Keep opacity only (200 ms):** Accordion captions and the index preview.
- **Removed:** hero parallax, Drift Wall motion (it becomes a static grid) and the Tilted Card tilt.
- **Tear Ticket:** a click opens WhatsApp with no physics.

Other rules:

- No motion gates content, and there is no unskippable intro. The preloader never blocks interaction for more than 1.2 s.
- The Tear Ticket is a real `<button>` with an `aria-label` ("Destacar convite e abrir conversa no WhatsApp sobre a {name}").

## Performance Restrictions

- **Libraries:**
  - `motion` is used only by Tear Ticket and Tilted Card, which are lazy chunks; it is not in the initial bundle. The shared image uses the native View Transitions API (DEC-023).
  - `gsap` core, ~27 KB gzip, only in the lazy chunk that holds the Accordion Gallery (DEC-019).
  - No ScrollTrigger (IntersectionObserver covers reveals), no Lenis and no WebGL.
- **We will not do:**
  1. animate flex-grow, width or padding on scroll or pointermove;
  2. hold the hero behind the preloader (DEC-018);
  3. run the Drift Wall or cursor-preview rAF while offscreen.
- **Impact on LCP:** the hero photo is preloaded with `fetchpriority="high"` and ≤ 300 KB; the cutout loads second and never blocks LCP.
- **Impact on CLS:** masks have reserved heights; every image has width and height from the manifest.
- **Impact on INP:** passive listeners; no layout reads or writes in pointer handlers (cache rects on enter).
